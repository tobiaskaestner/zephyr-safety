4. The requirement side
=======================

- **Requirement**: a statement that the kernel must satisfy. Sources: ZEP-SRS, the doc comments of
  the kernel API, and the safety needs. Other sources can come later.
- **Reading**: one interpretation of a requirement text. A text can have more than one reading.
- **Expresses**: the relation from a property to a requirement. A property expresses one reading of
  one requirement. Tag: ``@source``.
