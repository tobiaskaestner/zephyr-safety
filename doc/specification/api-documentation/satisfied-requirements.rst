Satisfied Requirements
======================

Every API symbol in the safety scope that implements a requirement, from its
Doxygen ``\satisfies``. Each entry links to the requirements it satisfies and
to the symbol's Safety API (Doxygen) page; a requirement's own page lists the
symbols that satisfy it ("satisfied by") next to the test cases that verify
it. Generated from the Safety API's Doxygen XML, one section per API group.

The requirements no symbol satisfies are listed on the Requirements page of
the Safety API (Doxygen).
