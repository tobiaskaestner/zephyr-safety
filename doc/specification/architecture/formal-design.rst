Formal Design
=============

The design of the kernel objects is also a formal model in TLA+. The model
has a document of its own: :external+formal:doc:`index`. That document shows
the modules of the TLA+ library (:external+formal:doc:`formal-model`), the
method and its glossary.

Each model property is a need of the type "Model Property" in that document.
A requirement that a property expresses lists the property as "Expressed by".
