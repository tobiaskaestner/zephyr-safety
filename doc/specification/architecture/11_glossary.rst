
Glossary
=========

ADC
  Analog-to-Digital Converter. A hardware peripheral that converts a voltage level into a digital number.

IEC 61508
  An international standard for the functional safety of electrical/electronic/programmable electronic safety-related systems.

MCU
  Microcontroller Unit. The main processor of the device.

SSR
  Software Safety Requirement. A single, verifiable requirement for the software.
