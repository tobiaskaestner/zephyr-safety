Building Blocks
================

The building blocks are the design elements of the Zephyr kernel: each is a
page of Zephyr's own documentation, marked with a ``.. design::`` block that
names the requirements it fulfills. They are listed here as ``design`` needs,
generated from those blocks; each links to its page's source.
