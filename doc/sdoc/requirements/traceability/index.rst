Traceability
============

How far each layer reaches the requirements: tests (``verifies``), code
(``satisfies``), design (``fulfills``) and coverage adequacy (``assesses``).
The numbers come from the needs of all documents of this docset.

The pages of the other documents show more detail:

* requirement × test with results: the coverage pages of the test
  specification and the test report;
* requirement × design: the design coverage page of the architecture;
* adequacy per requirement, and skipped results: the test report.
