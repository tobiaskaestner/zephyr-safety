# The sensitivity set: model configurations that change only the bounds
# of a base line of mc/expected.txt (2026-10-30, recommendation 5 of the
# method review). The argument for each property is in the workspace
# notes (claude/kernel-unit/tla/small-scope.md). The format is the format
# of mc/expected.txt. Run this list only on request:
#
#   TLC_LIST=sensitivity spec/tla/tools/run_tlc.sh [<module>:<config> ...]
#   spec/tla/tools/run_tlc_remote.py --list sensitivity [<module>:<config> ...]
#
# A run of mc/expected.txt does not run these lines. Each configuration
# <base>_sens_<axis> changes one bound of mc/<module>_<base>.cfg and
# checks the same properties:
#
#   t2, t4, t5  2, 4 or 5 threads (t2: the lower check)
#   o1, o2, o3  1, 2 or 3 objects
#   pc, pm      the other priority set (ZPriosCoop, ZPriosMixed)
#   pw          the wide priority set ZPriosWide (-2, -1, 0, 1)
#   p2, p4      2 or 4 priorities (MCWaitQueue)
#   e2, e4, e5  2, 4 or 5 entries (MCTimeout)
#   t4o1        4 threads and 1 object
#   _sym        the symmetry set SymThreadsObjs (safety only, no MCJoin)
#
# The expected result is the result of the base. Exceptions: the witness
# size checks, where the comment of the .cfg file gives the reason;
# small_sens_pc, small_sens_pw and p7_rules_sens_pw do not check
# Inv_RunRuleHolds (as coop and p7_rules_coop: with two cooperative
# priorities and k_thread_abort() it fails through finding P7-c).
#
# The order is the run order: the symmetry validation first, then the
# lines by their estimated time, cheap first (one worker, from the base
# counts). The whole list takes about 47 hours with one worker. The last
# line alone takes about 16 hours. A line without heap= runs with the
# default heap of the runner (2g on the lab host).
