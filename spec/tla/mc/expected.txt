# Expected result of each model. One line for each run:
#
#   <module> <config> <expected>
#
# <module>   a module in mc/ (without .tla)
# <config>   the configuration mc/<module>_<config>.cfg
# <expected> pass          TLC finds no error, and the model has at least
#                          one state (a model without an initial state
#                          gives the result no-states)
#            fail:<Name>   TLC finds a violation of the property <Name>
#                          (for an alias Prop_X == WQ!X, TLC names WQ!X)
#            probes        TLC finds a violation of each invariant of the
#                          configuration (one run for each probe)
#            fail:Assert   an example test (<Module>Test) fails. Not an
#                          expected result: the line of a test is pass.
#
# After the expected result, a line can have fields <key>=<value>
# (tools/run_tlc.sh gives the full list):
#
# states=<n>  the distinct states, and depth=<n> the depth of the state
#             graph, of a run with one worker and -fp 0. Each pass line
#             has them. A different value fails the line: the state space
#             changed. Record the new value in the commit of the change,
#             with the reason.
# heap=<size> the Java heap of the line (default: TLC_HEAP).
#
# tools/run_tlc.sh runs each line and compares the result. A difference
# fails the run. The recorded counts of 2026-10-30 come from the lab run

# equal to the counts of round B.
